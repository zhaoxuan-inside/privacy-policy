血压了么隐私政策

更新日期：2026年10月15日

生效日期：2026年10月15日

1. 开发者主体

本隐私政策由个人开发者制定，适用于“血压了么”App（以下简称“本应用”）。

2. 我们如何收集和使用个人信息

为提供血压识别服务，本应用可能收集和处理以下个人信息：

  • 相机权限：用于拍摄血压相关图像，以识别血压数据。
  • 相册/照片权限：用于读取您从相册中选择或保存的照片，以识别血压数据。
  • 麦克风/语音权限：用于接收语音输入，辅助完成血压数据识别或结果反馈。
  • 设备信息：用于保障应用正常运行、排查故障。
  • 日志信息：用于记录应用运行情况、排查异常。

上述信息仅用于实现血压识别、数据展示、分享和导出功能。如您拒绝提供，可能无法使用相关功能，但不影响您使用其他基本功能。

3. 敏感个人信息说明

血压数据属于个人健康生理信息，相机、相册、语音信息可能涉及敏感个人信息。我们会以最小必要方式处理上述信息，并在您授权同意后使用。

4. 权限调用说明

本应用仅在您使用血压识别、数据分享、数据导出等功能时请求相机、相册和麦克风权限。您可以在系统设置中随时关闭相关权限；关闭后，相关功能可能无法正常使用。

5. 外部模型与数据来源

本应用支持从魔塔（ModelScope）、HuggingFace 等第三方平台下载模型，也支持使用本地模型。模型下载行为受对应平台规则约束，本应用不会将您的血压数据、照片、语音等个人信息上传至上述平台。

6. 数据分享与导出

本应用支持将血压数据分享到其他应用，也支持将血压数据导出为文件。分享和导出操作由您在设备上主动发起，数据将传输至您选择的目标应用或存储位置。本应用没有后端服务器，不会将您的血压数据上传至云端或第三方服务器。

7. 第三方 SDK

截至本隐私政策更新之日，本应用未接入第三方统计、广告、推送、登录或地图类 SDK。如后续接入新的第三方 SDK，我们将更新本隐私政策并另行说明。

8. 信息存储与安全

本应用没有后端服务器，数据目前仅存储在您的设备本地。血压数据属于个人健康信息，建议您妥善保管设备，避免他人未经授权访问。我们会在实现服务目的所必需的最短期限内保留相关信息，并在不再需要时删除或匿名化处理。

9. 用户权利

你有权查询、更正、删除个人信息，撤回同意，并注销账号。由于本应用未提供账号注册功能，你可通过删除应用内数据、清除应用数据或卸载应用等方式行使相关权利。

10. 未成年人保护

我们不主动收集不满十四周岁未成年人的个人信息。如涉及未成年人个人信息处理，将依法取得监护人同意。

11. 隐私政策更新

我们可能会根据法律法规变化、功能调整或业务需要更新本隐私政策。更新后的隐私政策将通过本页面发布，并以页面顶部“更新日期”为准。
